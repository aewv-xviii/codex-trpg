# Codex TRPG · 밤의 테이블

내 PC에서 실행하는 TRPG 테이블과 Codex GM. 친구 각자의 Codex 로그인과 별도 캠페인 데이터를 사용합니다.

## 시작하기 (Windows)

1. ZIP을 새 폴더에 풀고 Node.js 22.13 이상과 Codex를 설치합니다. Codex에서 본인 계정으로 로그인합니다.
2. `Start-Codex-TRPG.cmd`를 실행합니다. 또는 터미널에서 `npm run doctor`, `npm start`를 실행합니다. npm 패키지 설치나 프런트 빌드는 필요 없습니다.
3. 브라우저에서 <http://127.0.0.1:4317>을 열어 새 테이블을 만듭니다.
4. 자신의 캐릭터·세계관·시나리오를 준비하고 등록합니다. 처음에는 앱의 체험 기능으로 사용법을 확인할 수 있습니다.

종료는 실행 창에서 Ctrl+C. 저장 데이터는 `.local-data/`에 남습니다. 업데이트할 때 이 폴더를 백업하고 보존하세요. 브라우저 쿠키는 로컬 사용자 식별에 사용하므로 다른 브라우저에서는 다른 사용자로 인식할 수 있습니다.

## 친구의 Codex에 붙여 넣을 요청

> 이 폴더의 AGENTS.md와 README.md를 읽고 Codex TRPG를 설치·실행해 줘. doctor로 Node와 Codex 실행 파일을 확인하고, 내 계정 로그인 상태를 확인해 줘. 기존 .local-data가 있으면 보존해. 새 캠페인과 내 캐릭터를 함께 준비하고, 내가 보유한 룰북만 연결해 줘. 유료 API로 전환하지 마.

## 룰북 연결

상용 룰북은 포함하지 않습니다. 자신이 보유한 PDF/TXT/MD를 `rulebooks/`에 넣습니다. PDF 검색에는 Python과 `pypdf`가 필요합니다 (`python -m pip install pypdf`). 스캔 PDF는 먼저 OCR이 필요합니다.

테이블을 만든 후 주소/앱 상태의 실제 캠페인 ID를 확인하고 서버를 종료한 다음 `node scripts/setup-rulebooks.mjs 캠페인ID`를 실행합니다. Python이 PATH에 없으면 마지막 인수로 실행 파일 경로를 전달합니다. DB 백업 후 로컬 검색 허용 캠페인과 책 목록을 등록합니다. 서버를 다시 실행하고 캠페인 준비 → 룰북에서 사용할 책을 선택합니다. 책 변경 후 같은 명령을 다시 실행합니다. 모델에 필요한 검색 발췌가 전송되므로 완전 오프라인 AI가 아닙니다.

## GM 설정과 범위

`local/gm-config.json`에서 플레이 모델은 `gpt-6.1-sol / high / standard`, 테스트 모델은 `gpt-6-luna / max / standard`입니다. 이 모델을 사용할 수 있는 Codex 계정이 필요하며 이용 한도가 적용됩니다. 설치 위치가 자동 감지되지 않으면 `NIGHT_TABLE_CODEX`에 실제 `codex.exe` 경로를 지정합니다.

서버가 주사위·시간·자원·상태 변경을 처리하고 Codex가 서술과 규칙 재정을 맡습니다. 배포본에는 기존 플레이 세션, 로그인 정보, 상용 룰북 원문, 개인 캐릭터 원문, 기존 캠페인의 NPC 카탈로그가 없습니다. 해당 카탈로그·특수능력 참조는 비워 두었으므로 원래 캠페인의 전용 콘텐츠를 완전히 재현하는 배포판이 아닙니다.

이 버전은 **127.0.0.1에서만 동작하는 로컬 버전**입니다. 다른 PC의 친구가 초대 코드만으로 접속할 수 없습니다. 여러 사람이 원격으로 함께 플레이하려면 인증과 서버 배포를 별도로 준비해야 합니다. 기존 온라인 밤의 테이블에 자동으로 연결하지 않습니다.

## 검증과 출처

`npm test`로 포함된 테이블·표시 회귀 검사를 실행합니다. 실제 모델 호출과 다른 PC에서의 설치 검증은 별도입니다. Node/Codex/Python 실행 파일과 계정 정보는 포함하지 않습니다. `public/play/vendor/`의 외부 라이브러리는 동봉된 라이선스를 따릅니다. GURPS는 해당 권리자의 게임이며 이 프로젝트는 공식 제품이 아닙니다.
